# How to Run — PHP Complaint Management (PMC/PMT)

## Requirements
- PHP 7.4+ and MySQL — XAMPP recommended

## Steps
1. Copy folder to `htdocs/`, start Apache + MySQL
2. Open: `http://localhost/18-php-complaint-management/`

## Files
| File | Purpose |
|------|---------|
| `db.php` | DB connection, auto-creates database and table |
| `index.php` | Public complaint submission form |
| `admin.php` | Admin panel — view, filter by org, update status |
