# How to Run — PHP Tic-Tac-Toe

## Requirements
- PHP 7.4+
- XAMPP or PHP built-in server

## Steps
```bash
cd 20-php-tictactoe
php -S localhost:8000
```
Open: `http://localhost:8000`

## How it Works
- 2-player game (X and O take turns in the same browser)
- Game state stored in PHP session
- Click "New Game" to reset
- Single file — no database needed
