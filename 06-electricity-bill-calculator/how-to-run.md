# How to Run — PHP Electricity Bill Calculator

## Requirements
- PHP 7.4 or higher
- XAMPP / WAMP / MAMP or PHP built-in server

## Option 1: XAMPP
1. Copy `06-electricity-bill-calculator` folder into `C:/xampp/htdocs/`
2. Start **Apache** from XAMPP Control Panel
3. Open: `http://localhost/06-electricity-bill-calculator/`

## Option 2: PHP Built-in Server
```bash
cd 06-electricity-bill-calculator
php -S localhost:8000
```
Then open: `http://localhost:8000`

## Files
| File | Purpose |
|------|---------|
| `index.php` | Form to enter units consumed + bill calculation logic |
