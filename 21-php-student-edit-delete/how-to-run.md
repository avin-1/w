# How to Run — PHP Student Edit/Delete

## Requirements
- PHP 7.4+ and MySQL — XAMPP recommended

## Steps
1. Copy folder to `htdocs/`, start Apache + MySQL
2. Open: `http://localhost/21-php-student-edit-delete/`

## Files
| File | Purpose |
|------|---------|
| `db.php` | DB connection, auto-creates table |
| `index.php` | Add, edit, delete students in one page |
